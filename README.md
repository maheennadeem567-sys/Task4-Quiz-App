## 📖 About The Project

**Quizify** is an interactive online quiz platform where you can test your knowledge across multiple categories, race against the clock with timed quizzes, and understand your results through detailed score reports and answer explanations.

### ✨ Key Features

- 📚 **Multiple Categories:** Choose from different quiz topics.
- ⏱️ **Timed Quizzes:** Answer each quiz against the clock.
- 📊 **Detailed Score Reports:** See your result and track your progress after every quiz.
- 💡 **Answer Explanations:** Learn why an answer is right or wrong.
- 📱 **Responsive Design:** Works smoothly on mobile, tablet and desktop.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

- Node.js (v18+)
- npm

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/maheennadeem567-sys/REPO_NAME.git

# 2. Go to the project folder
cd REPO_NAME

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

## 🌐 Deployment

This project is deployed on **Netlify**.

1. Connect your GitHub repository to Netlify.
2. Set the build command to `npm run build`.
3. Set the publish directory to `dist`.
4. Deploy!
